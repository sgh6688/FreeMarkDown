# Changelog

## 0.1.3

- Consolidated file actions and formatting tools into a single editor-style toolbar
- Reduced header height and removed the extra support slogan for a denser writing layout
- Kept a slim expand handle when the document overview rail is collapsed
- Fixed the export popup stacking order so it stays above the formatting toolbar
- Refreshed the Windows portable release artifacts and release documentation

## 0.1.2

- Added Windows portable release workflow and distribution docs
- Added desktop smoke test coverage with Playwright for core editing flows
- Improved WYSIWYG editing with list continuation and exit behavior
- Added table insertion and row/column management tools
- Fixed rename-on-save for existing Markdown files in the desktop build
- Added PDF export and native `.docx` Word export
- Grouped export actions into a single export menu and enabled native PDF outline generation
- Published self-contained Windows portable artifacts for direct use
